Enter number of elements: Enter elements: Sorted (deterministic): 23 34 34 54 56 112 123 676

===== Performance Analysis (N = 5000) =====
Random input:
  Deterministic : comparisons = 73085, time = 0.266542 ms
  Randomized    : comparisons = 73564, time = 0.304083 ms
Already sorted input (worst case for deterministic):
  Deterministic : comparisons = 12497500, time = 5.541 ms
  Randomized    : comparisons = 75701, time = 0.127375 ms
Reverse sorted input:
  Deterministic : comparisons = 12497500, time = 4.96892 ms
  Randomized    : comparisons = 72835, time = 0.127125 ms

Conclusion:
  Deterministic: Best/Avg O(n log n), Worst O(n^2) on sorted/reverse input.
  Randomized   : Expected O(n log n) for every input; worst case O(n^2) is very unlikely.
  Space        : O(log n) average recursion stack.
